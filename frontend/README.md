# OmniMandate Frontend

Public web interface for OmniMandate, an intelligent treasury control system built on GenLayer.

## Network

Development target: GenLayer Bradbury Testnet.

Verified contract:

0x04c1E361ec0Da96a263794F1f582989c2419267C

Bradbury is a testnet. This interface does not claim a mainnet deployment.

## Development

Install dependencies with npm install.

Run locally with npm run dev.

Production checks:

- npm run lint
- npm run build
- npm audit

## Interface

- Public product landing page
- Light, Dark, and System themes
- Responsive OmniMandate workspace
- Transaction journey UI
- Bradbury verification presentation

Wallet and Intelligent Contract functionality is not yet wired into this visual frontend checkpoint.

## Security

Never place wallet private keys, seed phrases, or other secrets in frontend source code or environment files.
